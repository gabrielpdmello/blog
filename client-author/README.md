# Author Client
Client used to create posts and manage comments.

## Features
- All the features from the Reader Client, except signup
- [MDXEditor](https://github.com/mdx-editor/editor) for creating and editing posts
- Delete posts and comments from any users

## How to run this project
1. Clone this repo and cd into client directory
```bash
git clone https://github.com/gabrielpdmello/blog.git
cd blog/client-author
```
2. Install dependencies
```bash
npm install
```
3. Copy the example environment file
```bash
cp .env.example .env
```
4. Update the environment variables
5. Start the application
```bash
npm run start
```
